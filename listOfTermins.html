List of Termins

Java
Это популярный объектно-ориентированный язык программирования общего назначения, код которого запускается на любых устройствах с помощью виртуальной машины
Oak ("Дуб")
Первоначальное название языка Java. Гослинг назвал его так в честь дуба, который рос прямо под окном его рабочего кабинета.
WORA (Write Once, Run Anywhere)
Знаменитый слоган и концепция («Напиши один раз, запускай где угодно»), ставшая визитной карточкой Java благодаря её переносимости.
JVM (Java Virtual Machine)
Виртуальная машина Java. Гослинг спроектировал архитектуру JVM, чтобы программы компилировались не в машинный код конкретного процессора, а в независимый байт-код.
Green Project
Секретная инженерная группа внутри Sun Microsystems (включавшая Гослинга, Патрика Нотона и Майка Шеридана), в недрах которой и зародились технологии, приведшие к созданию Java
